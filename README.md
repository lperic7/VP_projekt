## Upute za pokretanje

1. **Navigacija:** Otvorite terminal i navigirajte do mape projekta.
2. **Pokretanje:** Upišite sljedeću naredbu:
``` bash
python -m http.server 8000
```
3. **Pregled:** Otvorite web preglednik i u traku za adresu unesite: `http://localhost:8000`

> **Napomena:** Korištenje lokalnog poslužitelja nužno je zbog CORS sigurnosnih pravila web preglednika prilikom učitavanja lokalnih JSON datoteka.

---

## Upute za korištenje

*   **Navigacija kroz vrijeme:** Koristite vremenski slider ili kliknite gumb **"Pokreni"** za automatsku reprodukciju povijesti Formule 1.
*   **Usporedba vozača:** Odaberite dva različita vozača iz padajućih izbornika kako biste simultano ažurirali linijski graf i radar dijagram.
*   **Analiza konstruktora:** Pređite mišem preko "valova" na **Streamgraphu** za uvid u:
    *   Točan broj pobjeda pojedinog konstruktora u odabranoj sezoni.
    *   Kumulativan broj pobjeda do te sezone.
